# RESIK — Bank Sampah Digital

Aplikasi Bank Sampah Digital dengan arsitektur monorepo:
- **backend-api**: Spring Boot REST API + PostgreSQL
- **desktop-admin**: JavaFX Desktop App (Admin/Petugas)
- **android-client**: Android Java App (Masyarakat)

## Fitur
- Registrasi & Login (JWT Auth)
- Edukasi Pemilahan Sampah
- Penjadwalan Jemput Sampah
- Sistem Penimbangan & Kalkulasi Harga
- Dompet Digital & Pembayaran
- Dashboard Riwayat Transaksi
- QR Code Scanner
- Push Notification
- Export Laporan PDF/Excel
- Peta/Map Lokasi Bank Sampah
- Chat Admin-User

## Deploy
Backend API auto-deploy ke Railway saat push ke `main`.
