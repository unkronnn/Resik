RESIK - Bank Sampah Digital | PBO UTS4
Permasalahan Nyata
1
Minimnya Edukasi Pemilahan Sampah
Masyarakat tidak mengetahui jenis sampah yang dapat didaur ulang, dijual, atau dibuang. Pencampuran sampah organik & anorganik masih terjadi.
2
Belum Ada Nilai Ekonomis dari Sampah
Banyak masyarakat tidak menyadari bahwa sampah yang dipilah dengan baik memiliki nilai jual dan dapat menjadi penghasilan tambahan.
3
Proses Penyetoran Tidak Terstruktur
Masyarakat bingung ke mana harus menyetor, bagaimana prosesnya, dan berapa nilai yang akan didapat.
4
Kurangnya Transparansi & Tracking
Tidak ada sistem yang memungkinkan masyarakat melacak riwayat setoran sampah beserta pendapatan yang diperoleh.

Alasan Proyek Perlu Dikembangkan
1
Mendigitalisasi Proses Bank Sampah
Mengubah proses manual menjadi platform digital yang terstruktur dan efisien.

Meningkatkan Partisipasi Masyarakat

Tools bagi Pengelola Bank Sampah
Mengelola operasional secara efisien dan terdokumentasi dengan baik.

Rencana OOP - Class & Attribute
User (abstract)
+ id, nama, email, password
+ alamat, noTelp
+ getRole() [abstract]
+ login()
Masyarakat extends User
+ saldoDompet, poinReward
+ riwayatSetoran
+ buatPenjemputan()
+ verifikasiTimbangan()
Petugas extends User
+ nip, shift, areaTugas
+ prosesPenjemputan()
+ inputTimbangan()
+ konfirmasiPembayaran()
Sampah
+ id, kategori, nama
+ hargaPerKg, deskripsi
+ getHarga()
+ getKategori()
Penjemputan
+ id, masyarakat, tanggal
+ status, alamat
+ addDetail()
+ calculateTotal()
DetailPenjemputan
+ penjemputan, sampah
+ estimasiBerat, beratAktual
+ calculateSubtotal()
Transaksi
+ id, penjemputan
+ totalHarga, tanggal, status
+ processPayment()
DompetDigital
+ id, masyarakat
+ saldo, riwayatTransaksi
+ topUp(), withdraw()
Notifikasi
+ id, penerima
+ pesan, tanggal, statusBaca
+ send(), markAsRead()

Rencana OOP - Konsep yang Diterapkan
Encapsulation
Semua attribute private, akses via getter & setter dengan validasi
private double saldoDompet;
public double getSaldoDompet() { return saldoDompet; }
public void setSaldoDompet(double s) { this.saldo = s; }
Inheritance
Masyarakat & Petugas mewarisi dari User (abstract class)
User (abstract)
 |-- Masyarakat
 |-- Petugas

// Mewarisi attribute & method dari User
Polymorphism
Method overriding (getRole) & overloading (buatPenjemputan)
@Override
public String getRole() { return "MASYARAKAT"; }

public Penjemputan buatPenjemputan(List<Sampah> s, LocalDate t)
public Penjemputan buatPenjemputan(List<Sampah> s, LocalDate t, String c)
Constructor
Setiap class utama memiliki constructor untuk inisialisasi
public Masyarakat(String nama, String email,
  String password, String alamat, String noTelp) {
  super(nama, email, password, alamat, noTelp);
}
Object & Method
Object dibuat dari class, method untuk behavior
Masyarakat m = new Masyarakat(...);
Penjemputan p = m.buatPenjemputan(sampah, tanggal);
m.verifikasiTimbangan(p);
m.tarikSaldo(50000);
Relasi Antar Class
Association (one-to-many, one-to-one)
Masyarakat 1---* Penjemputan
Penjemputan 1---* DetailPenjemputan
DetailPenj. *---1 Sampah
Masyarakat 1---1 DompetDigital
